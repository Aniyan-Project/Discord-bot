# Branilist Bot website and dashboard

Mode: Operate for the dashboard; Persuade for the public home; Read for command help. Scope: web/.

## Direction contract

THESIS: An anime club workspace puts server controls beside a useful Discord response preview. The interface shows the Branilist connection through media and command examples, never invented adoption metrics.

OWN-WORLD: Warm graphite surfaces, soft neutral ink, restrained orange actions, Manrope lettering, thin seams and calm rounded controls. An anime club at night, not a neon control room. Cover art comes from the public Branilist catalog and remains on original hosts.

STORY: Visitors understand the bot, inspect commands and enter with Discord. Managers select a server, adjust language and command access, preview an actual response format and save. Members link Branilist separately for private library actions.

FIRST VIEWPORT: A 244px sidebar anchors server selection and six clear destinations. The configuration page has a large heading, a two-column layout with grouped fields left and a 330px sticky Discord preview right. A save bar appears only for changed fields. On mobile, navigation is a native dialog and preview follows the form. Public home opens with a strong two-column headline and a chat/media demonstration, not dashboard metrics.

FORM: Assigned grounded direction 5, anime-club workspace; seed 4a6ce7e8. User explicitly selected this direction and code-first. Other grounded candidates were a streaming watch queue, manga index, Discord channel handoff, fansub cue sheet, festival program and weekly anime gazette. Console challenger competitive on clarity; adopt its disciplined focus/error states. Typographic specimen, coded sleeve, airport signage, ticket wallet and mascot catalog declined for task fit; keep their hierarchy, restrained surfaces, clear destinations, persistent state and whole-cell responsive discipline without importing their motifs.

SIGNATURE: Prefix, accent, cover and synopsis controls update the adjacent Discord response immediately; submitted values remain pending until the authorized server save succeeds. Motion is limited to the save bar entering and navigation focus, with reduced-motion support.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
